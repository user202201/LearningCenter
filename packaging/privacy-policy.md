## 中文

**应用：学习乐园（Learning Center）**

### 一句话说明

本应用**自己不收集任何个人信息**。开发者没有服务器，看不到你的任何数据。

### 数据保存在哪里

你的数据只会在下面两个地方，由你自己选择：

1. **仅在本设备**：孩子的姓名（或昵称）、汉字、成语、学习记录、设置、头像图片，都保存在你的设备（手机、平板、浏览器）的本地存储里，不会发送给任何人。
2. **你自己的私有 GitHub 仓库**：如果你选择用 GitHub 同步，应用会用你自己填写的访问令牌，把数据读写到**你自己的私有仓库**（令牌和仓库名由你输入）。数据只在你和 GitHub 之间传输，开发者无法访问。GitHub 如何处理数据，适用 GitHub 的隐私声明：<https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement>。应用拒绝使用公开仓库。

访问令牌只保存在你的设备上。「退出登录」会把它从设备上删除。

### 应用会用到的设备功能

| 功能 | 用途 | 数据去向 |
|---|---|---|
| 相机 | 扫描登录二维码；为孩子拍摄头像 | 图片只在设备上处理，头像缩小后保存在设备（或你自己的仓库）；不上传给开发者或任何第三方 |

| 分享、保存文件 | 导出备份、MIDI、录音、PDF | 由你选择保存或发送到哪里 |
| 打印 | 字帖、故事、证书 | 由系统打印窗口处理 |

### 我们不做的事

- 没有账号系统、没有广告、没有统计和分析、没有第三方跟踪或 SDK。
- 不出售、不分享任何数据。

## English

**App: Learning Center (学习乐园)**

### In one sentence

This app **does not collect any personal information itself**. The developer runs no server and cannot see any of your data.

### Where your data is kept

Your data is in one of two places, chosen by you:

1. **On this device only**: children's names (or nicknames), characters, idioms, learning records, settings and avatar pictures are kept in the local storage of your device (phone, tablet or browser). Nothing is sent to anyone.
2. **Your own private GitHub repository**: if you choose GitHub sync, the app reads and writes the data in **your own private repository**, using an access token that you type in together with the repository name. The data travels only between you and GitHub; the developer has no access. How GitHub handles data is governed by GitHub's privacy statement: <https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement>. The app refuses a public repository.

The access token is stored only on your device. "Sign out" deletes it from the device.

### Device features the app uses

| Feature | Purpose | Where the data goes |
|---|---|---|
| Camera | Scan the sign-in QR code; take a picture for a child | Pictures are processed on the device only; an avatar is shrunk and stored on the device (or in your own repository); nothing is uploaded to the developer or to any third party |
| Photo library / file picker | Choose an avatar picture, import an Excel sheet, load music, import a backup file | Read on the device only |
| Sound output, speech | Dictation, words, poem reading; instrument sounds | Uses the device's own voices; no network |
| Share, save file | Export a backup, MIDI, recordings, PDF | You choose where it is saved or sent |
| Printing | Practice sheets, stories, certificate | Handled by the system print dialog |

### What the app does not do

- No account system, no advertising, no analytics, no third-party tracking or SDK.
- It does not sell or share any data.
- Apart from the GitHub you choose yourself (and the download of the app itself), the app contacts no other server. Fonts, images, scripts and word lists are installed with the app and work offline.

### Children

The app is a learning-record tool for **parents and teachers**. A child's name is typed in by the parent or teacher and is stored only where that adult chooses (this device or their own private repository). The developer collects no information about children.

### Your rights and controls

- View, change, delete: in the app's Settings; deleting a child also deletes all of that child's records.
- Export: Settings → Backup and restore → Export backup (the backup file never contains the access token).
- Remove everything: uninstall the app or clear the site data in the browser; data in GitHub is deleted by you in your own repository.

When this policy changes, the date above is updated.

## Français

**Application : Learning Center (学习乐园)**

### En une phrase

Cette application **ne collecte elle-même aucune donnée personnelle**. Le développeur n'exploite aucun serveur et ne peut voir aucune de vos données.

### Où sont conservées vos données

Vos données se trouvent à l'un de ces deux endroits, selon votre choix :

1. **Uniquement sur cet appareil** : les prénoms (ou surnoms) des enfants, les caractères, les expressions, les résultats d'apprentissage, les réglages et les images d'avatar sont conservés dans le stockage local de votre appareil (téléphone, tablette ou navigateur). Rien n'est envoyé à qui que ce soit.
2. **Votre propre dépôt GitHub privé** : si vous choisissez la synchronisation GitHub, l'application lit et écrit les données dans **votre propre dépôt privé**, au moyen d'un jeton d'accès que vous saisissez avec le nom du dépôt. Les données ne circulent qu'entre vous et GitHub ; le développeur n'y a pas accès. Le traitement des données par GitHub relève de la déclaration de confidentialité de GitHub : <https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement>. L'application refuse un dépôt public.

Le jeton d'accès n'est conservé que sur votre appareil. « Se déconnecter » le supprime de l'appareil.

### Fonctions de l'appareil utilisées

| Fonction | Usage | Destination des données |
|---|---|---|
| Appareil photo | Lire le code QR de connexion ; prendre une photo pour un enfant | Les images sont traitées uniquement sur l'appareil ; un avatar est réduit et conservé sur l'appareil (ou dans votre propre dépôt) ; rien n'est envoyé au développeur ni à un tiers |
| Photothèque / sélecteur de fichiers | Choisir une image d'avatar, importer un tableau Excel, charger de la musique, importer une sauvegarde | Lecture sur l'appareil uniquement |
| Sortie sonore, synthèse vocale | Dictée, mots, lecture de poèmes ; sons des instruments | Utilise les voix de l'appareil ; pas de réseau |
| Partage, enregistrement de fichier | Exporter une sauvegarde, du MIDI, des enregistrements, des PDF | Vous choisissez où le fichier est enregistré ou envoyé |
| Impression | Feuilles d'entraînement, histoires, certificat | Gérée par la fenêtre d'impression du système |

### Ce que l'application ne fait pas

- Pas de système de comptes, pas de publicité, pas de statistiques, pas de suivi ni de SDK tiers.
- Elle ne vend ni ne partage aucune donnée.
- Hormis le GitHub que vous choisissez vous-même (et le téléchargement de l'application), elle ne contacte aucun autre serveur. Les polices, images, scripts et listes de mots sont installés avec l'application et fonctionnent hors ligne.

### Enfants

L'application est un outil de suivi destiné aux **parents et aux enseignants**. Le prénom d'un enfant est saisi par le parent ou l'enseignant et n'est conservé que là où cet adulte le décide (cet appareil ou son propre dépôt privé). Le développeur ne collecte aucune information sur les enfants.

### Vos droits et vos contrôles

- Consulter, modifier, supprimer : dans les Réglages de l'application ; supprimer un enfant supprime aussi tous ses enregistrements.
- Exporter : Réglages → Sauvegarde et restauration → Exporter la sauvegarde (le fichier ne contient jamais le jeton d'accès).
- Tout effacer : désinstaller l'application ou effacer les données du site dans le navigateur ; les données sur GitHub sont supprimées par vous, dans votre propre dépôt.

Lorsque cette politique change, la date ci-dessus est mise à jour.
