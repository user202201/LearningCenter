## 怎么用

1. 每条是一个短问题，可以用几个字回答；"位置"给出文件、编号或界面，"现状"是应用现在写的内容。
2. 在每条末尾的 `答：` 后面写 ✓（现状正确）或 ✗ + 正确的值（例如 `✗ 5000`）。
3. ★ 表示最可疑、最该先看的条目；"我的倾向"是我（模型）凭记忆的最佳猜测，不是结论。
4. 答完把 ✗ 的条目和正确值发回来，我据此改数据，并在对应的测试里加检查。
5. 翻译只列"术语"问题（"EN/FR 词 X 对应中文 Y 对吗"），分别放在"英语"和"法语"两节。
