# 灵感与资料来源（样品阶段）

> 来源说明：下面对各 App 的描述来自我对这些产品公开做法的了解（没有联网逐个核对，版本会变），当作“找灵感的清单”，不是调研报告。资料库的许可证请在正式使用前再逐条确认。

## 1. 市面上的 App 做法，值得借鉴的点

| 方向 | 代表产品 | 值得借鉴 |
|---|---|---|
| 单词记忆 | 百词斩、扇贝单词、墨墨背单词、Anki、Quizlet | **间隔重复**（我们已有：1/3/7/14/30 天的盒子）；看图/例句记词；“认识/模糊/不认识”三档反馈；每天固定新词量 + 复习量；连续打卡与徽章；拼写、听音选词、看义选词多种题型 |
| 英语启蒙 | 叫叫、Duolingo ABC、Khan Academy Kids、Lingokids | 很短的关卡（2–3 分钟）、角色陪伴、满屏奖励动画、发音跟读、**不打击孩子**（答错只提示再来一次） |
| 小学数学口算 | 小猿口算、乐乐课堂、一起作业 | 限时口算 PK、错题本自动归类、按“知识点”闯关、拍照批改（需联网，不适合离线） |
| 综合学习 | 洋葱学院、可汗学院、斑马 | 知识点地图（先修关系：学分数加法前要会通分）、短视频 + 即时练习、掌握度进度条 |
| 初中理科 | 作业帮、猿辅导、PhET 模拟实验 | 公式卡 + 变式题、实验动画（PhET 是**可离线的 HTML5 模拟**，电路、力与运动、原子结构、酸碱等） |
| 游戏化数学 | Prodigy Math、DragonBox | 把题目藏进冒险游戏里，答对才放技能；孩子几乎感觉不到在做题 |

**对我们最有用的 5 个想法**
1. **知识点地图 + 掌握度**：每个知识点有“未学 / 学习中 / 掌握”状态（我们的盒子 box 0–5 就是现成的掌握度）。
2. **每天“学新 + 复习”固定量**：英语现在是每周 20 个新词，可以再加“今日复习 10 个”。
3. **多题型**：看英文选中文 → 看中文选英文 → 听音选词 → 拼写（逐步加，先不动游戏现有逻辑）。
4. **错题本**：答错的词/题单独成册，可打印（沿用字帖的打印思路）。
5. **家长报表**：每周一页——新词、复习、正确率、最需要加强的 10 个词（和 Google Sheets 同步思路一致）。

## 3. 当前样品里已经有什么（`public/data/`）

- `english-words.json` — 1565 个词，按年级排序（一年级→初三），含音标、词性、中文。**用于英语单词功能。**
- `curriculum.json` — 数学 / 英语 / 科学各年级的“课程范围”概览（按课标整理，各版本教材顺序略有不同）。
- `math-topics.json` — 数学练习的知识点清单与各年级安排（题目生成器还没做）。
- `periodic.json` — 118 个元素（符号、中英文名、原子量、分类、在表中的行列、是否初中常考）。
- `science.json` — 各年级科学常识问答 36 条 + 初中物理/化学公式与方程式 30 条。

## 4. 建议的下一步

1. 校对英语分级（对照课标词表），补例句和图片；加“今日复习”和更多题型。
2. 数学：口算题生成器 + 闯关（先 1–6 年级口算，再到初中的代数、几何），按知识点记录掌握度。
3. 科学：元素周期表页（可点开看元素卡片）、公式卡、PhET 离线实验入口。
4. 年级同步到数据仓库（`profile.json`），换设备不必重选。
